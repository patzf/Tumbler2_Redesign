# Tumbler 2 `Redesign`

Corrected / upgraded version of the `HL Tumbler 2`, focused on power efficiency, signal integrity, safer power architecture and expanded connectivity.

## Overview

This redesign addresses known limitations of the original `HL Tumbler 2` across five key areas:

- Power efficiency
- Signal integrity
- Power architecture safety
- Correct GPIO input voltages
- Expandability

## Variants

To balance BOM size, cost, and feature requirements, the redesign is split into three variants, each maintained in its own branch:

| Branch           | Description                                                  | Status    |
| ---------------- | ------------------------------------------------------------ | --------- |
| `fix-only`       | Drop-in replacement using original components where possible | In Design |
| `low-cost`       | Cost-reduced BOM with two USB ports                          | In Design |
| `ultra-low-cost` | Single USB port, maximum cost reduction                      | Review    |
